# Bundled datasets

- `gnss_marks.csv` — GeoNet GNSS marks, snapshot of
  https://raw.githubusercontent.com/GeoNet/delta/main/network/marks.csv
  (GeoNet delta repository). Operating marks = End Date 9999-01-01.
- `nz_active_faults.geojson` — NZ Active Faults Database (GNS Science,
  https://data.gns.cri.nz/af/), 1:250,000 generalised traces; see file for
  provenance/licence.

- `wiki-france.cpt` — topographic colour table by Eric Gaba (Wikimedia
  Commons user Sting), translated to GMT by J.J. Green (2012), CC BY-SA
  3.0. Used by the README overview map (`figure.make_overview_map`).
